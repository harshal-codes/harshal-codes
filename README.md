### 🤖 Recruvo — AI Resume Screening Portal

**Problem:** Manual resume screening is slow and inconsistent across formats.

**What I built:**
- Integrated an **LLM API (OpenRouter)** into the screening pipeline to auto-parse resumes and generate structured candidate evaluation scores
- Engineered and iterated prompts to force **consistent, structured JSON output** from the LLM across varied resume formats
- Built and documented **REST APIs** with **FastAPI + JWT auth**
- Authored a full **Postman testing guide** from the live repo
- Debugged and resolved a **production Vercel deployment failure** to restore the CI/CD pipeline

**Stack:** `FastAPI` `PostgreSQL/Supabase` `React` `JWT` `OpenRouter` `pdfplumber` `Vercel` `Railway`
